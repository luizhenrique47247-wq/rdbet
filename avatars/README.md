# Imagens de Perfil (Avatares)

Coloque suas fotos reais nesta pasta para que a plataforma as carregue automaticamente no perfil:
- `avatar1.png` (Guardião)
- `avatar2.png` (Equilíbrio)
- `avatar3.png` (Zen)
- `avatar4.png` (Racional)

Se as imagens não estiverem presentes ou falharem ao carregar, o aplicativo usará emojis clínicos como alternativa segura.
